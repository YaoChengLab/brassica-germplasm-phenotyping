# Supplemental data

Supplemental Data S1–S5 of the manuscript listed in the [repository README](../README.md).
Each folder has its own README with the fields, units and, for Data S5, the run commands.

| Folder | Content | Manuscript |
|---|---|---|
| `Data_S1/` | Example platform export for the 64 plants of batch 2025B08, with its JSON record | Section 3.1, Supplementary Methods S7 |
| `Data_S2/` | Fresh weight and image traits: 269 accession–batch means from 257 accessions in 12 batches | Figure 7 |
| `Data_S3/` | Six-trait survey of 258 accessions: plant and accession tables | Figure 6, Sections 2.6 and 3.5, Supplementary Methods S9 |
| `Data_S4/` | Full statistics of the fresh-weight models, retained separately from Table S7 | Table S7 |
| `Data_S5/` | Analysis code that reruns the manuscript figures and tables from bundled prepared data | Figures 5–7, Figures S2–S4, Tables 1 and S5–S7 |

The tag `v1.0-submission` marks the version referenced by the submitted manuscript.
